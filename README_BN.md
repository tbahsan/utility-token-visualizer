# ⚡ প্রিপেইড মিটার সহায়ক

> by [tbahsan](https://github.com/tbahsan) • **লাইভ:** https://tbahsan.github.io/utility-token-visualizer/

বাংলাদেশের প্রিপেইড বিদ্যুৎ মিটার ব্যবহারকারীদের জন্য **বাংলা-প্রথম**, **১০০% অফলাইন** হিসাব-সহায়ক। কোনো সার্ভার নেই, কোনো ট্র্যাকিং নেই — আপনার তথ্য আপনার ডিভাইস ছাড়ে না।

## ✨ ফিচার

| ট্যাব | কাজ |
|---|---|
| **রিচার্জ হিসাব** | ৳১০০০ রিচার্জে কত টাকার বিদ্যুৎ? মিটার ভাড়া, ডিমান্ড চার্জ, ৫% ভ্যাট, ০.৫% রিবেট — ভাঙতি + বার চার্ট + পড়ে শোনানো |
| **স্ল্যাব রেট** | BERC আবাসিক (LT-A) স্ল্যাব অনুযায়ী ইউনিটের দাম + গড় রেট |
| **টোকেন চেক** | ২০-সংখ্যার টোকেন যাচাই, XXXX-XXXX ফরম্যাট, মিটারে চাপার নিয়ম |
| **ব্যবহার ট্র্যাকার** | রিডিং লগ (localStorage), মাস-শেষ পূর্বাভাস, ব্যালেন্স কতদিন চলবে |
| **যন্ত্রপাতি** | ফ্যান/ফ্রিজ/এসির মাসিক খরচ + “এসি কম চালালে কত বাঁচে” স্লাইডার |
| **গ্যাস ও পানি** | তিতাস ও ওয়াসা সহায়িকা (ক্যালকুলেটর আসছে) |

## 🚀 চালানো

GitHub Pages থেকে সরাসরি চালান, অথবা লোকালি:

```bash
cd utility-token-visualizer
python3 -m http.server 8000
# → http://localhost:8000
```

> `file://` দিয়ে খুললে JSON লোড হবে না — সার্ভার দিয়ে চালান।

## 🧮 হিসাবের সূত্র (স্বচ্ছ)

```
বকেয়া বাদ → বেস = রিচার্জ − বকেয়া
ভ্যাট = বেস − বেস/১.০৫          (৫% ভ্যাট-সহ ধরা হয়)
রিবেট = ০.৫% × বেস/১.০৫
বিদ্যুৎ বাবদ = বেস/১.০৫ − মিটারভাড়া − ডিমান্ডচার্জ + রিবেট
```

- ডিমান্ড চার্জ: ৳৪২/kW • মিটার ভাড়া: সিঙ্গেল ৳৪০ / থ্রি ৳২৫০
- স্ল্যাব **মার্জিনাল (ধাপে ধাপে)** — ফ্ল্যাট নয়
- লাইফলাইন ৳৪.৬৩ শুধু মোট ≤৫০ ইউনিটে

রসিদের সাথে অমিল পেলে [issue খুলুন](https://github.com/tbahsan/utility-token-visualizer/issues) — ছবিসহ (ব্যক্তিগত তথ্য ঢেকে)।
